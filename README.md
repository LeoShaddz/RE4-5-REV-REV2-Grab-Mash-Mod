# Resident Evil 4 (2005) / 5 / Revelations / Revelations 2 Grab Mash Mod

This quality-of-life mod allows you to break free simply from a enemy grab by holding the action key on your keyboard or the 'A' button on your controller. The keyboard key is customizable.

The glyph still shows a prompt to move the analog stick on controller or move the mouse on keyboard, but the mod works.

RE4 action key on keyboard is "E" key and in RE5 is "F" key.

In RE5, it also works for turning valves, in REV and REV2, this has not yet been implemented.

# Installation

RE4: 

Install the Ultimate Asi Loader in this directory: Resident Evil 4\Bin32\
Extract the file "RE4.2005.Grab.Mash.v1.0.zip"
Copy the .asi and .ini files into the "scripts" folder, which is located in this directory: Resident Evil 4\Bin32\
Done
To work in RE4 with the HD Project/RE4 tweaks mod installed, you need to rename the dinput8.dll file from the Ultimate Asi Loader to d3d9.dll

RE5: 

Install the Ultimate Asi Loader in in the game's root folder
Extract the file "RE5.Grab.Mash.v1.0.zip"
Copy the .asi and .ini files into the "scripts" folder
Done
